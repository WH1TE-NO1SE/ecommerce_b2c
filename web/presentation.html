功能模块

用户端 12 个页面 + 管理端 5 个 Tab，覆盖完整电商业务

👤

用户认证

  • 注册 / 登录 双模式切换
  • JWT Token 自动持久化
  • bcrypt 密码加密
  • 管理员权限双重校验
📦

商品模块

  • 33 个商品，8 个分类
  • 分类筛选 + 关键词搜索 (300ms 防抖)
  • SKU 规格选择，价格联动
  • 商品标签（热卖/包邮/新品）
  • Unsplash 真实商品图片
🛒

购物车

  • 完整商品快照持久化（重启不丢失）
  • 库存校验 (StockException)
  • 规格切换（失败自动恢复）
  • 全选 / 反选 / 数量编辑
📋

订单系统

  • 9 种订单状态 + 状态机校验
  • 地址 JSON 快照（历史不变）
  • 支付成功后才清购物车
  • 优惠券应用（满减/折扣）
🛠️

管理后台

  • 数据中心（统计 + 热销 TOP10）
  • 商品 CRUD + 上下架
  • 订单管理 + 一键发货
  • 用户角色管理
  • 优惠券 CRUD
🛡️

工程特性

  • 离线回退（网络异常自动降级）
  • 骨架屏加载体验
  • 响应式管理后台布局
  • 亮色 / 暗色双主题
  • 中英双语国际化框架

1users用户表username, password_hash, role, pointsbcrypt 加密
